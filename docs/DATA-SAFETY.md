# Mixvu data safety (Play / Apple / Microsoft)

Effective 21 August 2026.

## Collected

- Waitlist: name, email, platform, camera count, plan intent
- Cloud: OAuth tokens from Ring/Blink after sign-in. Not passwords.
- Payments: Apple, Google, Microsoft. We never see the card.
- Live video: on device / LAN. Not uploaded unless Cloud is on and the brand allows it.

## Play Data safety

- Email, name: collected (waitlist). Not sold. Not used for ads.
- Camera: this-device, on-device processing.
- Photos/videos: not collected by us for local cams.
- Location: no.
- Encrypted in transit: yes.
- Deletion: yes, via a support issue.

## Apple nutrition

- Data Not Linked to You: Camera (this-device live view)
- Data Linked to You: Contact Info (email)
- Tracking: none

## Camera permission string

Mixvu uses the camera so this phone or computer can appear as a tile on your desk. Video stays on the device unless you add a Cloud adapter you control.

Microphone: not requested in v1. Location: not requested.
